## 影响与限制

变更只涉及已确认的独立通道和统一几何；纯 PP 算法、地图几何、视频/数据库业务保持原模块边界。自动运行不依赖上位机，但拍照 external_ack 是显式外部步骤，缺确认按步骤超时。commissioning 的其余制动/车体/外参/定位/场地仍未标定，不将配置统一称为已可实车自动上线。

Windows 不编译 ROS 消息层；完整四包及 EKF 回归由 Linux Humble CI 验证。Jetson ARM64、实际驱动、现场标定、制动和精度验收未执行；未部署或发送任何实车运动命令。
