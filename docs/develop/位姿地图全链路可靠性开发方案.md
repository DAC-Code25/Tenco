## 目标与约束

修复本轮审查中的高优先级异常输入、历史恢复和任务接续问题；验证生产坐标转换、地图实际显示、规划上传、执行反馈的一致性。
本方案依据工作空间 docs/系统架构与测试覆盖审查-2026-09-19.md 及用户本轮明确要求。采用分模块测试驱动实施、集成后独立复核。
Lua 与 script 目录不修改。手动仍用旧 WebSocket 直通，不加任务会话许可，不与自动通道仲裁；自动执行不依赖 Tenco 在线。
轮距 0.25 m，左右轮径 0.20 m。只使用当前工作空间；Qt 固定 6.5.3 / MinGW 11.2。
禁止伪称软件仿真能证明实车定位绝对精度。几何标定、原点及场地配置仍须真实配置。

## 设计与取舍

### 坐标唯一约定

服务位姿：map 为局部 ENU（x 东、y 北，米），base_link 为车辆控制参考点，yaw 为弧度、从东向北逆时针。
Qt 模型保留现有南/东地图轴；所有进出经过 MapFrameAdapter。同一 binding 的旋转和平移正反变换严格互逆。
显示旋转仅作用于视图，不改变地图点或任务版本。屏幕像素变换不进入任务坐标。
由融合参考点到 base_link 的刚体变换只在发布处应用一次；速度按相同参考点和航向投影。
任务回读核验 taskId/revision/context、服务哈希格式、boot/execution 身份及回读缓存内容完全一致，不能直接信任旧本地 preparedPlan。planHash 由服务端计算，客户端作为不透明内容身份使用，不独立复算 JsonCpp 摘要；用户预览服务实际返回的路径与步骤后明确确认。
合法新鲜定位和最后已知位置分开表示；降级但合法位姿继续实时显示。

### 温室定位准入

选择“连续合法估计可控制”，不以 RTK 非 FIX、positionReliable/headingReliable 为 false、观测质量降低或短暂原始观测缺口单独禁止控制。
估计数值有限、已初始化、状态流新鲜、坐标/标定版本匹配、真实轮速反馈可用仍是基础条件。未经配置的坐标和标定不能冒充已经确认。
原始观测年龄和质量保留为诊断；降级模式可限速，不因每次质量抖动在暂停/继续之间切换。
位置小修正不再永久锁存无法控制；时间倒退和非法/过期状态仍拒绝。姿态/位置真实性不能由“JSON合法”证明，因此不删除基础完整性门禁。
融合、tracking 与 PoseClient 对此采用一致语义，避免下游重新施加已经取消的质量门禁。
统一状态/反馈允许抖动窗口为 350 ms，硬失联上限 1000 ms；控制线程 deadline 和发送队列时效仍独立保持。具体值进入共享配置并测试边界，不散落 UI 常量。

### 存储和协议

输入类型/范围错误返回 4xx，不锁存存储故障。
请求去重改为有界摘要/必要结果，兼容旧账本迁移；读写文档边界一致，不能生成自身无法读取的文件。
执行过程事件与确认记录增量保存，终态结果不可被后续无活动任务的停止覆盖。终态无变化不重复落盘。
保留急停快速路径，修复重放副作用；在线有界清理历史，避免常驻服务增长。
优先修改现有组件，不引入数据库或另一套通信协议。补充独立审查发现：控制请求统一限制 16 KiB；急停去重容量失败仍停车；新急停推进状态版本以拒绝此前在途复位；请求去重结果在持久化成功后才发布。历史每 60 秒清理七天前记录、关联事件与旧孤儿目录，保护当前任务/执行。

## 验收与回退

非法输入后正常请求成功；历史可重启且去重语义正确；重开能继续同一 execution；视图旋转不改任务；
点/车辆/路径在非零变换下对应相同物理坐标；任务执行反馈投回地图后闭合一致；质量退化不单独打断控制；
非法/旧帧/错坐标仍被拒绝；手动与自动独立；所有新增和既有自动测试通过。
需要平台的测试在 Linux CI 执行，失败必须定位，不得用 Windows mock 的成功代替。目标机绝对精度与实时性另行现场验收。
保持任务/地图格式兼容；持久化迁移测试覆盖旧记录。回退到本方案基线提交与对应旧记录备份，不自动恢复运动。
