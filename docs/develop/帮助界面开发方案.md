# Tenco 帮助界面开发方案

## 1. 目标

帮助界面用于给现场使用人员和维护人员提供“怎么用、出问题怎么查、资料在哪里”的入口。

它不承担参数修改职责。参数修改仍放在 `维护` 页面；帮助页面只提供说明、排障步骤、快捷入口和文档索引。

第一版目标：

- 让用户快速理解首页、地图、作业、维护、云台、相机等核心功能如何使用。
- 提供常见故障排查流程，减少现场遇到问题时只能看源码或问开发人员。
- 提供开发文档和运行目录快捷入口，方便定位配置、备份和日志。
- 展示当前程序实际使用的配置文件、备份目录、日志目录等运行信息。
- 提供安全规范、标准作业流程、运维巡检、数据归档和故障分级说明，使帮助页更接近企业级现场手册。

## 2. 页面定位

帮助页和维护页边界如下：

- `帮助页`：解释功能含义、操作流程、注意事项、常见故障、文档入口。
- `维护页`：修改运行参数、保存配置、热加载、恢复备份、执行配置自检。

帮助页可以跳转到目录或文档，但不直接修改配置。

## 3. UI 结构

采用运行时构建 UI，不直接大规模修改 `mainwindow.ui`。

布局：

- 顶部说明区：显示“使用帮助与现场排障”标题、页面定位和安全提示。
- 左侧导航：按主题分类。
- 右侧内容：按卡片展示说明、步骤、故障项、快捷键、运行信息和文档入口。

第一版分类：

- `快速开始`
- `系统概览`
- `安全规范`
- `作业流程`
- `首页功能`
- `地图与作业`
- `维护配置`
- `设备连接`
- `运维巡检`
- `故障排查`
- `快捷键`

## 4. 功能内容

### 4.1 快速开始

提供整车软件使用主流程：

1. 确认底盘控制器、工控机、PLC、相机服务已上电并在同一网络。
2. 打开软件后查看首页状态、视频和云台连接状态。
3. 在地图页加载或新建地图，确认实时位姿正常。
4. 选择路径或作业任务，确认现场安全后启动。
5. 如设备地址变化，进入维护页修改并选择 `保存并应用`。

### 4.2 系统概览

系统概览用于说明整套系统的职责边界和数据流：

- 上位机负责可视化交互、地图编辑、任务规划、配置维护、帮助文档和运行状态展示。
- 工控机负责相机服务、融合位姿、作业服务和适合本地实时执行的控制逻辑。
- 底盘控制器负责接收速度/控制指令，并执行底盘运动控制。
- 云台 PLC 负责升降、水平旋转、俯仰等机构动作和状态寄存器反馈。
- 相机/视觉节点负责原始图像、处理后图像、拍照录像和视觉处理结果输出。

### 4.3 安全规范

安全规范用于约束自动运行、云台动作、升降动作和维护调参前的前置条件：

- 运行前必须确认急停、遥控器和现场人员安全。
- 车辆前后、垄间、云台旋转半径和升降机构附近不得有人员、线缆或障碍物。
- 首次运行或修改控制参数后，应低速、短距离验证。
- 运行中禁止人员进入车辆运动路径或云台机构附近。
- 出现车辆偏离、云台卡滞、定位跳变或通信持续异常时，应先停止任务，再查日志。

### 4.4 标准作业流程

作业流程用于把现场操作固化为 SOP：

- 班前确认供电、网络、设备状态和现场安全。
- 首页确认状态、视频、云台和日志。
- 地图页确认位姿稳定、地图坐标和车辆实际位置一致。
- 加载或编辑路径/作业计划，并检查起点、终点、方向、速度和停止点。
- 正式作业前先短距离低速验证。
- 任务结束后停止控制、保存数据、记录异常和配置变更。

### 4.5 首页功能

说明首页主要能力：

- 状态轮询和运行日志。
- 视频预览和视频流切换。
- 拍照、录像、录像保存目录。
- 云台升降、水平旋转、俯仰控制。
- 手动底盘控制和急停。

### 4.6 地图与作业

说明地图页主要能力：

- 地图加载、新建和保存。
- 路径点编辑、路径规划、路径跟踪执行。
- 直线/多垄作业计划编辑、状态刷新、启动/停止。
- 位姿不稳定时的使用注意事项。

### 4.7 维护配置

说明维护页使用方式：

- `保存`：只写入配置文件，不影响当前运行模块。
- `保存并应用`：写入配置文件并热加载运行模块。
- `恢复上次配置`：恢复最近一次启动备份并立即应用。
- `加载配置文件`：只读入表单，不直接写盘或应用。
- 修改通信、云台、相机、路径控制参数前应确认设备状态。

### 4.8 设备连接

列出关键设备与配置位置：

- 底盘控制器 WebSocket、状态 HTTP、写寄存器 HTTP。
- 工控机相机服务 HTTP。
- 云台 PLC Modbus TCP。
- 直线/多垄作业服务 HTTP。
- 配置文件和备份目录。

### 4.9 运维巡检

运维巡检用于班前检查、班后归档、版本和配置管理：

- 检查底盘、工控机、PLC、相机、网络和云台机械状态。
- 确认相机镜头、录像目录、地图位姿和配置文件路径。
- 班后归档关键日志、录像、地图、路径和配置。
- 记录当天是否修改配置、修改原因、验证结果和未解决问题。
- 重要配置修改前后都应保留备份。

### 4.10 故障排查

第一版内置常见问题：

- 视频打不开。
- 拍照/录像失败。
- 云台按钮不可点击。
- 云台按键无反应。
- 地图收不到位姿。
- 路径下发后小车不动。
- 保存并应用后没有生效。

每个问题给出按顺序排查步骤。

故障分级建议：

- `P0 安全风险`：车辆失控、急停无效、云台卡滞、人员进入危险区域，应立即停机。
- `P1 作业中断`：底盘、定位、相机、PLC 或作业服务不可用，应停止任务并按链路排查。
- `P2 功能异常`：某个按钮、某一路视频、某个配置项异常，应记录复现步骤并回退配置。
- `P3 体验问题`：显示、布局、文字、提示不清晰，应记录截图进入 UI 优化。

### 4.11 快捷键

列出当前已实现的键盘和鼠标快捷操作。

首页底盘手动控制：

- `W`：前进，按下开始持续发送前进速度，松开停止。
- `S`：后退，按下开始持续发送后退速度，松开停止。
- `A`：左转，按下开始持续发送左转角速度，松开停止。
- `D`：右转，按下开始持续发送右转角速度，松开停止。

首页云台快捷键：

- `方向键上`：云台升降上升。
- `方向键下`：云台升降下降。
- `方向键左`：云台水平左旋。
- `方向键右`：云台水平右旋。
- `左 Ctrl + 方向键上`：云台上仰。
- `左 Ctrl + 方向键下`：云台下俯。

地图视图快捷操作：

- `鼠标左键拖拽地图空白区域`：平移地图视图。
- `鼠标滚轮`：缩放地图视图。
- `鼠标左键点击地图点`：选中最近地图点，并同步右侧点位参数。
- `鼠标左键点击空白位置`：更新当前地图坐标输入值。
- `鼠标右键点击地图`：打开地图点上下文菜单，可新建或删除地图点。

地图编辑组合键：

- `Ctrl + 鼠标左键拖拽地图点`：移动该地图点，并刷新关联路径。
- `Alt + 鼠标左键拖拽地图点`：旋转该地图点朝向，并刷新关联路径。
- `Ctrl + Alt + 鼠标左键点击地图点`：第一次选择路径起点，第二次选择终点并按当前路径类型创建路径。
- `Ctrl + A`：切换地图路径显示/隐藏。

地图作业快捷操作：

- 启用 `从地图添加点` 后，鼠标左键点击地图位置可新增地图点。
- 启用 `添加中间点` 后，鼠标左键点击地图位置可新增直线/多垄作业中间点。

使用限制：

- 首页方向键会被云台控制优先接管，避免触发顶部菜单切换。
- 云台快捷键只在云台控制启用且 PLC 配置有效时生效。
- 地图编辑组合键只在地图编辑模式开启时生效。

### 4.13 数据与日志

数据与日志页说明需要保留和如何排查的数据：

- `config.json`：当前运行配置。
- `config_backups`：最近启动备份。
- `tenco.log`：应用运行日志。
- 视频、截图、录像：现场过程证据。
- 地图、路径和作业计划：复现任务执行目标。

日志查看建议：

- 先看错误发生时间附近的 `WARN/ERROR`。
- 再向前查配置应用、连接状态和用户操作。
- 提交问题时同时提供配置文件、相关日志、复现步骤和现场现象。
- 配置文件和录像可能包含敏感信息，外发前应脱敏。

### 4.14 运行信息

显示：

- 当前配置文件路径。
- 配置是否来自文件。
- 程序运行目录。
- 配置备份目录。
- 日志目录。
- 当前应用版本或构建标识。

提供快捷按钮：

- 打开配置目录。
- 打开备份目录。
- 打开日志目录。
- 打开开发文档目录。

## 5. 安全原则

- 帮助页不直接下发控制命令。
- 帮助页不直接修改配置。
- 文档和目录打开失败时只提示，不阻塞程序。
- 故障排查建议优先提醒急停、人员避让和机械限位风险。
- 帮助页内容按现场手册定位组织，避免只停留在按钮说明。

## 6. 验收项

- 打开帮助页后不再显示旧占位文本。
- 左侧分类导航可以切换右侧内容。
- 每个分类都有可读的说明卡片。
- 故障排查项能覆盖视频、云台、地图、路径执行、维护热加载等核心问题。
- 安全规范、作业 SOP、运维巡检、数据日志和故障分级内容完整可读。
- 文档资料页能打开现有开发文档。
- 运行信息页能显示配置文件、备份目录、日志目录，并能打开对应目录。
- 帮助页 UI 风格与维护页一致，但内容密度更适合阅读。
- Qt Creator 编译运行通过。
