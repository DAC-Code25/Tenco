# 车辆速度与尺寸参数同步开发方案

统一速度参数：物理最高 1.50 m/s，任务请求 0.10～1.50 m/s，常规默认 0.10，可选 0.20；单垄基础默认 0.10、最大默认 0.20。更新出厂配置、C++ 后备默认、维护/地图输入范围及任务编译校验；手动上限允许零以关闭移动，启用时速度选择下限 0.10；停止命令仍为零，首页初始 0.20。旧配置中合法速度保留；schema1 手动最大速度不再复制为自动默认。旧单垄文件不静默改写，越界编译时明确提示修正。

尺寸由工控机共享标定维护：0.80×0.30 m、轮径 0.20、轮距 0.25；Tenco 不另存第二份轮组标定。工控机同步方案见 [配套方案](https://github.com/DAC-Code25/sensor-fusion-ros2/blob/main/docs/develop/车辆速度与尺寸参数同步开发方案.md)（本任务合入前在同名分支查看）。

不增加线程、网络协议和资源，不调整角速度、坐标、任务类别或拍照链路；保持手动/自动独立和 Lua 原样。执行固定 Qt Kit 完整构建与 CTest，增加配置范围/迁移、常用速度编译与旧文件越界拒绝回归。工控机配置由 src 验证，Linux/ROS 核对 CI；本任务不含部署。Git 回退与重建可恢复本地候选。
