# Tenco 关于界面开发方案

## 1. 目标

关于界面用于展示项目身份、版本信息、系统能力边界、运行环境、版权/依赖和维护联系信息。

它和帮助页、维护页的边界如下：

- `关于页`：说明“这是什么系统、当前版本是什么、包含哪些能力、运行环境是什么、如何识别当前构建”。
- `帮助页`：说明“怎么使用、怎么排障、文档在哪里”。
- `维护页`：负责“修改运行配置、保存、热加载、备份恢复”。

第一版目标：

- 去掉旧的占位文本，形成正式产品信息页。
- 展示应用名称、系统定位、当前版本/构建信息、运行路径和配置路径。
- 在页面顶部展示车辆视觉资产：优先加载运行目录 `models/carmodel_about_centered.glb` 三维预览模型，支持自动旋转、鼠标拖拽旋转和滚轮缩放；缺少 Qt Quick3D 或模型加载失败时回退到车辆图片 `image/car.jpg`。
- 展示核心能力模块和系统架构摘要。
- 展示当前构建特性，例如是否启用 OAK 相机后端、关于页三维模型能力。
- 提供复制诊断信息、打开项目目录/配置目录/日志目录等快捷能力。
- 提供版权、内部使用说明和维护责任边界。

## 2. 页面定位

关于页应该更像企业软件的产品信息和版本识别页，而不是普通说明页。

典型使用场景：

- 现场维护人员确认当前软件版本和运行路径。
- 开发人员远程排障时要求用户复制诊断信息。
- 部署人员确认当前构建是否包含某些后端能力。
- 项目交付时展示系统能力、适用范围和维护说明。

## 3. UI 结构

采用运行时构建 UI，不大规模修改 `mainwindow.ui`。

布局建议：

- 顶部品牌区：
  - `Tenco`
  - 系统定位，例如“巡检车上位机控制与运维平台”
  - 简短说明
  - 车辆三维预览模型 `models/carmodel_about_centered.glb`，不可用时回退车辆图片 `image/car.jpg`
- 信息卡片区：
  - 产品信息
  - 版本与构建
  - 系统能力
  - 运行环境
  - 版权与维护
- 底部操作区：
  - 复制诊断信息
  - 打开程序目录
  - 打开配置目录
  - 打开日志目录

视觉风格应与维护页、帮助页一致，但关于页信息密度更低，更偏品牌和版本识别。

## 4. 内容规划

### 4.1 产品信息

建议展示：

- 产品名称：`Tenco`
- 系统定位：巡检车上位机控制与运维平台
- 项目用途：用于车辆状态监控、视频预览、云台控制、地图路径规划、直线/多垄作业、维护配置和现场排障。
- 适用场景：温室/园区/实验室巡检车调试与运行。

### 4.2 版本与构建

建议展示：

- 应用版本：来自 `QCoreApplication::applicationVersion()`，若未设置则显示 `开发构建`。
- Qt 版本：`qVersion()`。
- 构建日期：使用编译宏 `__DATE__`、`__TIME__`。
- Git 提交：第一版如果没有构建时注入，可显示 `未注入`。
- OAK 后端：根据 `TENCO_ENABLE_OAK_CAMERA` 宏显示 `启用` 或 `未启用`。
- 关于页三维模型：根据 `TENCO_ENABLE_ABOUT_3D` 和 Qt Quick3D/Quick3DAssetUtils 模块检测结果显示 `启用` 或 `静态图片兜底`。

### 4.3 系统能力

展示当前系统包含的主要模块：

- 首页状态轮询、视频预览、拍照录像、云台控制、底盘手动控制。
- 地图编辑、路径规划、路径跟踪、直线/多垄作业计划。
- 维护配置、配置备份、恢复、热加载、自检。
- 帮助文档、快捷键说明、故障排查和现场手册。

### 4.4 运行环境

展示：

- 程序运行目录。
- 当前配置文件路径。
- 配置是否来自文件。
- 配置备份目录。
- 日志目录。
- 操作系统名称。

### 4.5 版权与维护

建议展示：

- 项目归属：实验室/项目组内部使用。
- 维护说明：现场问题应提供版本、配置、日志、复现步骤和截图/录像。
- 安全声明：自动运行和机构控制前应确认急停、遥控器和现场环境安全。
- 第三方依赖说明：Qt、DepthAI/OpenCV 可按实际构建情况展示。

### 4.6 诊断信息复制

点击 `复制诊断信息` 后，将以下内容写入剪贴板：

- 应用名称和版本。
- Qt 版本。
- 构建时间。
- OAK 后端启用状态。
- 程序运行目录。
- 当前配置文件路径。
- 配置是否来自文件。
- 备份目录。
- 日志目录。
- 当前分支/提交如果可用。
- 关于页三维模型能力状态。

该能力方便用户把信息直接发给开发人员排查。

## 5. 安全和边界

- 关于页不修改任何运行配置。
- 关于页不下发控制指令。
- 关于页只读取路径、版本和构建信息。
- 打开目录失败时只提示，不阻塞程序。
- 诊断信息中如包含 token 或敏感地址，后续可扩展脱敏逻辑；第一版不读取完整配置内容，只显示文件路径和环境信息。
- 三维模型展示只读本地资源，不访问外部网络，也不下发控制指令。

## 6. 三维车辆模型展示方案

原始模型文件来自 `src/carmodel.glb`。该文件由 SolidWorks 导出，包含 `KHR_draco_mesh_compression` 必需扩展，Qt Quick3D/RuntimeLoader 在当前 Qt 6.5.3 和 6.8.3 运行环境下不能稳定直接解码，因此关于页不再直接加载原始模型。

当前运行时模型使用 `models/carmodel_about_centered.glb`。它由原始模型解压 Draco、简化并重新居中生成，`extensionsRequired = none`，构建后会复制到程序运行目录下用于关于页预览展示。实现采用“可选三维能力 + 静态图片兜底”的方式：

- CMake 新增 `TENCO_ENABLE_ABOUT_3D` 选项，默认开启。
- 配置阶段检测 `Qt6::Quick`、`Qt6::QuickWidgets`、`Qt6::Quick3D`、`Qt6::Quick3DAssetUtils` 是否可用。
- 四个模块全部可用时，编译 `TENCO_ENABLE_ABOUT_3D` 宏，并在关于页中使用 `QQuickWidget` 加载 `qml/AboutCarViewer.qml`。
- 模型通过 `RuntimeLoader` 从运行目录的 `file:///.../models/carmodel_about_centered.glb` 加载。
- QML 不依赖运行时读取模型包围盒，而是加载已规范化居中的模型，并使用固定安全相机参数，降低 Qt 6.5.3/6.8.3 之间的行为差异。
- `QQuickWidget` 和 `View3D` 均使用非透明浅色背景，避免 Windows 离屏渲染或透明层合成导致三维区域显示为纯黑。
- 当前 SolidWorks 源模型大部分材质为白色或在转换后丢失 `baseColorFactor`，关于页运行时模型补充了工业预览配色，用于增强结构层次和视觉识别；该配色不代表真实车体喷涂颜色。
- 当前预览模型按差速两轮小车的部件语义分配颜色：双侧驱动轮外圈为红色，轮心为银色，前后左右小万向轮为黑色，底盘为银色，车身主体为深灰色，竖直杆顶部摄像头为黑色，车身上方激光雷达为黑色，前后蘑菇头为灰白色，激光雷达支架为深灰色。
- 预览模型配色由 `scripts/recolor_about_model.py` 从 `src/carmodel_about_centered_uncolored.glb` 自动生成，只改材质和网格材质引用，不改几何和二进制网格数据，便于后续继续精调配色。
- 三维展示卡片不显示额外说明文字，模型区域直接占满视觉卡片，减少底部信息遮挡。
- 相机默认使用较远观察距离、较窄视场角和较高裁剪距离，优先保证长杆和车体完整显示。
- 三维视图支持自动旋转、鼠标左键拖拽绕水平/垂直方向旋转、鼠标右键或 `Shift + 左键拖拽` 控制滚转、滚轮缩放。
- 如果 Qt Quick3D 相关模块不可用，则 C++ 侧直接显示 `image/car.jpg`。
- 如果 QML 或模型运行时加载失败，则回退显示 `image/car.jpg`，并在日志中输出 QML 错误。

该方案不会让关于页三维展示能力反向影响普通构建。没有安装 Quick3D 的部署环境仍可正常编译和运行，只是视觉区域降级为车辆图片。

模型资产说明：

- `src/carmodel.glb`：原始 SolidWorks 导出模型，保留作源资产，不直接用于关于页运行时展示。
- `src/carmodel_about.glb`：关于页模型中间文件，无 Draco 必需扩展，保留用于后续重新处理。
- `src/carmodel_about_centered.glb`：关于页当前运行时模型源文件，已居中规范化并补充预览材质颜色，构建后复制到运行目录。
- `src/carmodel_about_centered_uncolored.glb`：补色前的居中模型备份，保留用于对比或重新生成材质。
- `scripts/recolor_about_model.py`：关于页三维模型配色生成脚本，默认输出 `src/carmodel_about_centered.glb`。
- `image/car.jpg`：静态图片兜底资产。

后续如果需要更高质量但仍稳定加载的三维展示，建议从 SolidWorks 或中间建模工具重新导出“非 Draco 压缩、低面数、仅保留外观壳体”的 GLB/GLTF，而不是直接打包完整工程级模型。

## 7. 验收项

- 打开关于页后不再显示旧占位文本。
- 支持 Qt Quick3D 的构建中，页面顶部能正常显示 `models/carmodel_about_centered.glb` 三维预览模型。
- 三维模型支持自动旋转、鼠标拖拽多自由度旋转和滚轮缩放。
- 三维模型应具有基础材质颜色区分，不应全部显示为纯白。
- 缺少 Qt Quick3D 或模型加载失败时，页面顶部能正常回退显示 `image/car.jpg`。
- 页面显示产品名称、系统定位、版本/构建、Qt 版本和 OAK 后端状态。
- 页面显示关于页三维模型能力状态。
- 页面显示程序运行目录、配置文件路径、备份目录和日志目录。
- 页面显示核心能力模块。
- `复制诊断信息` 可以把诊断摘要写入剪贴板。
- 打开程序目录、配置目录、日志目录按钮可用。
- UI 风格与维护页、帮助页一致。
- Qt Creator 编译运行通过。
