根文件是唯一编辑源；`src/`、`Tenco/`、`oak-camera-service/` 三个仓库的 `docs/workspace/` 是生成的受控快照，不能独立修改。相机服务独立入口见 [服务说明](https://github.com/DAC-Code25/oak-camera-service/blob/chore/standalone-project-v1/README.md)。完整对话、附件及本地临时证据不随镜像发布。专题计划和历史报告保留各自日期及事实，通过索引关联最新状态。

重新组装完整工作空间时，可从匹配版本的 `docs/workspace/` 按镜像清单恢复根文档/工具；先确认三份快照版本一致、目标无用户修改，再复制所列文件，分别克隆快照记录的三个源码仓库及分支，按上述目录并列放置。原始会话归档不在镜像中。

每次任务人工更新记录后，在工作空间根目录运行：

```powershell
python tools/project_docs.py snapshot --session-id <当前完整会话ID>
python tools/project_docs.py sync
python tools/project_docs.py check
```

`snapshot` 采集仓库状态；`sync` 生成镜像；`check` 校验元数据、链接、问题引用、源码和镜像。它们不会替你判断功能、编造结果或自动关闭待办。子仓库独立克隆时，可运行 `python docs/workspace/tools/project_docs.py check --documents-only` 校验该文档快照；这不等于确认完整工作空间和实车状态。

目前实时维护由每次工作的执行者在里程碑及结束前完成，没有后台监控进程。读取快照时以其更新时间与代码基线判断适用性。
