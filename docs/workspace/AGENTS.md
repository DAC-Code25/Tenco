## 5. 坐标、标定与配置契约

- `map` 为 WGS84 原点建立的 ENU，X 东、Y 北，单位 m；yaw 从 +X 起、逆时针为正，单位 rad，范围 `[-π,π)`。
- `base_link` 在驱动轮轴中心，X 前、Y 左。参考点平移/旋转及相应速度变换只应用一次。
- 轮距 0.25 m、左右轮径各 0.20 m、轮端每圈 65536 ticks；Lua 已处理减速比 25，上层不重复除。
- 几何、标定与原点由工控机统一管理，Tenco 读取。原点 active/pending 分开，磁盘保存不冒充运行进程已生效。
- 地图、任务与位姿校核原点/地图/变换/标定版本；Qt Y 轴向下只影响显示转换，展示旋转不改变规划身份。
- 默认 20 Hz 控制，状态/反馈新鲜度 350 ms、硬失联 1000 ms，发送有效期 150 ms、周期超期门限 100 ms。操作会话默认 1 秒，仅保护后续任务 API 写操作。
- 配置缺失、非有限、语义/版本错误须明确拒绝，禁止静默替代。commissioning 其余标定尚未验证；simulation 仅用于回环仿真，不能伪装生产配置。
- 设备、坐标与标定调整须记录现场影响；仓库示例地址、原点和验证标志不等于现场已确认。
